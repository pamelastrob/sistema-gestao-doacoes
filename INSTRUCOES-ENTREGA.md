## 🚀 Como Enviar

### Passo 1: Verificar Conteúdo

Verifique se todos os arquivos estão presentes:

```
projeto/
├── index.html              ✅
├── acessibilidade.html     ✅
├── css/
│   └── styles.css          ✅
├── js/
│   └── script.js           ✅
├── README.md               ✅
├── CHANGELOG.md            ✅
├── GITFLOW.md              ✅
├── OTIMIZACAO.md           ✅
├── CONTRIBUIR.md           ✅
├── .gitignore              ✅
├── package.json            ✅
└── build-config.js         ✅
```

### Passo 2: Push para GitHub

Se ainda não fez push:

```bash
# Adicionar remote (substitua pelo seu repositório)
git remote add origin https://github.com/seu-usuario/seu-repositorio.git

# Push para GitHub
git push -u origin main
git push origin develop
git push --tags
```

### Passo 3: Verificar Visibilidade

⚠️ **IMPORTANTE**: O repositório DEVE estar público!

- Acesse: Settings → General → Repository visibility
- Marque: **Public**
- Salve

### Passo 4: Copiar Link

Copie o link do repositório:

```
https://github.com/seu-usuario/seu-repositorio
```

### Passo 5: Entregar no Ambiente Virtual

1. Acesse "Experiências Práticas > Entrega Experiência Prática IV"
2. Cole o link do repositório
3. Adicione comentários opcionais
4. Clique em "Enviar"
