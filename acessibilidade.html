Declaração de Acessibilidade

Compromisso com a Acessibilidade

O Sistema de Gestão de Doações compromete-se com a acessibilidade e o acesso universal de pessoas com deficiência ao nosso website. Estamos empenhados em oferecer um site acessível e utilizável, independentemente da tecnologia ou habilidades de cada usuário.

Padrões de Acessibilidade

Nosso website foi desenvolvido seguindo as diretrizes do WCAG (Web Content Accessibility Guidelines) 2.1, nível AA. Nosso objetivo é garantir que o site seja:

  • Perceptível: Informações e componentes devem ser apresentados de forma que os usuários possam perceber.
  • Operável: Componentes de interface devem ser operáveis por todos.
  • Compreensível: Informações e operações de interface devem ser claras.
  • Robusto: Conteúdo deve ser compatível com tecnologias assistivas atuais.

Recursos de Acessibilidade Implementados

Navegação por Teclado

  • Todos os elementos interativos podem ser acessados usando apenas o teclado
  • Links de navegação por atalho (skip links) disponíveis
  • Foco visível em todos os elementos interativos
  • Navegação sequencial lógica através dos elementos

Navegação com Leitores de Tela

  • Estrutura semântica adequada (cabeçalhos, listas, artigos)
  • Atributos ARIA implementados corretamente
  • Textos alternativos para imagens e ícones
  • Regiões ao vivo para atualizações dinâmicas
  • Rótulos descritivos para todos os campos de formulário

Contraste e Visualização

  • Contraste mínimo de 4.5:1 para texto normal
  • Contraste mínimo de 3:1 para texto grande e gráficos
  • Modo escuro para reduzir fadiga visual
  • Modo de alto contraste disponível
  • Informação não transmitida apenas por cor

Formulários Acessíveis

  • Campos obrigatórios claramente marcados
  • Mensagens de erro claras e específicas
  • Validação em tempo real com feedback acessível
  • Instruções de preenchimento disponíveis
  • Agrupamento lógico de campos relacionados

Responsividade

  • Layout adaptável a diferentes tamanhos de tela
  • Conteúdo acessível em dispositivos móveis
  • Orientação de tela compatível

Como Usar os Recursos de Acessibilidade

Navegação por Teclado

  • Tab: Avança para o próximo elemento
  • Shift + Tab: Volta para o elemento anterior
  • Enter ou Espaço: Ativa botões e links
  • Setas: Navega entre opções em menus e formulários
  • Escape: Fecha menus ou retorna ao início

Atalhos

  • Alt + H: Ir para o topo da página
  • Alt + M: Ir para o conteúdo principal
