## 📤 Para Entregar

### 1. Criar Repositório no GitHub

1. Acesse: https://github.com/new
2. Nome: `sistema-gestao-doacoes`
3. Marque como **PUBLIC**
4. Não inicialize com README
5. Clique em "Create repository"

### 2. Fazer Push

```bash
# Adicionar remote
git remote add origin https://github.com/SEU-USUARIO/sistema-gestao-doacoes.git

# Push para GitHub
git push -u origin main
git push origin develop
git push --tags
```

### 3. Verificar Visibilidade

⚠️ **IMPORTANTE**: O repositório DEVE estar público!

- Acesse o repositório no GitHub
- Vá em **Settings → General**
- Verifique **Repository visibility: Public**
- Se estiver privado, mude para público

### 4. Copiar Link

O link será:
```
https://github.com/SEU-USUARIO/sistema-gestao-doacoes
```

### 5. Entregar

1. Acesse o Ambiente Virtual
2. Vá em "Experiências Práticas > Entrega Experiência Prática IV"
3. Cole o link do repositório
4. Clique em "Enviar"

## 🆘 Problemas Comuns

### "Repositório privado"
→ Vá em Settings → General → Public

### "Commits não aparecem"
→ Verifique se fez push: `git push origin main`

### "Página não carrega"
→ Verifique se `index.html` está na raiz do repositório

### "Formulário não valida"
→ Verifique o console do navegador (F12)
